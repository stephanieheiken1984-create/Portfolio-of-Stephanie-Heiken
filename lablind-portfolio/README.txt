STEPHANIE HEIKEN — PORTFOLIO WEBSITE

Files:
- index.html: website content and mobile navigation
- styles.css: responsive styling

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace YOUR_EMAIL@example.com with the email address you want employers to use.
3. Add screenshots you are permitted to share. Create an images folder beside index.html. Replace each .screenshot-placeholder block with something like:
   <img class="project-screenshot" src="images/eye-ball.jpg" alt="Screenshot of the Eye Ball website I built">
   Add this CSS rule to styles.css:
   .project-screenshot { display:block; width:100%; height:auto; object-fit:contain; }
4. Review every claim and link before publishing. Keep descriptions limited to work you personally performed.
5. Test the site on desktop and mobile.

PUBLISHING OPTIONS
- Netlify: upload the site folder using Netlify's current deploy workflow.
- GitHub Pages: upload index.html and styles.css to a repository and enable Pages in repository settings.
- Existing web host: upload the files to the folder where the site should live.

IMPORTANT
This is a static website starter, not yet published online. Screenshot panels are placeholders, not actual LABlind images. Use only screenshots you are allowed to share. Replace the email placeholder before publishing. Google Fonts are used when online; system fonts are fallbacks.
